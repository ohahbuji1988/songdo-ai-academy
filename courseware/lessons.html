WEEK 01 · 1일차 조기 성공 ⏱️ 실습 소요 시간: 약 30분

첫날 30분 만에 내 스마트폰으로 열리는 첫 웹사이트 띄우기

코딩 문법을 단 하나도 외우지 않습니다. AI에게 착한 모범 예시 3개를 쥐어주고 내 정보로 바꾼 뒤, 무료 인터넷에 올려 가족 단톡방에 링크를 자랑하는 첫날의 기적을 체험합니다.

💡 원장님의 3분 이야기 · 멘탈 모델

"AI는 손발이 없는 천재 신입 인턴입니다"

ChatGPT는 전 세계 백과사전을 다 외운 천재 인턴이지만, 손과 발이 없고 내 생각을 정확히 읽지 못합니다. "알아서 멋지게 해줘"라고 말하면 AI는 주사위를 굴리듯 아무렇게나 상상해서 글을 씁니다.

하지만 "이 양식에 맞춰서, 내 이름과 설명만 쏙 바꿔줘!"라고 모범 예시(Few-Shot)를 딱 쥐어주면 1초 만에 천재적인 코드를 뱉어냅니다. 오늘 우리는 AI를 지혜롭게 부리는 사장님의 태도를 배웁니다.

따라하기 실습: 4단계 완성 로드맵

1

3초 타임머신 보험 들기 (안전 백업본 만들기)

작업을 시작하기 전, 컴퓨터 폴더의 index.html 파일을 복사해서 index_backup.html로 하나 복사해 둡니다. 나중에 화면이 멈추거나 마음에 안 들면 언제든 이 파일을 열어 1초 만에 원래대로 되돌릴 수 있습니다.

2

검증된 모범 프롬프트 복사하기

아래 박스의 프롬프트를 복사하여 ChatGPT나 Claude 대화창에 그대로 붙여넣으세요. 대괄호 [ ] 부분만 내 정보로 바꿔주시면 됩니다.

너는 시니어 웹 퍼블리셔이자 초보자를 돕는 코딩 디렉터야. 내가 아래 제공하는 [HTML 원본 코드]의 디자인과 틀은 그대로 유지하면서, 내 내용만 정확하게 바꿔줘. [엄격한 출력 규칙] 1. `/* 생략 */`이나 `` 같은 축약은 절대 금지한다. `<!DOCTYPE html>`부터 `</html>`까지 전체 코드를 한 글자도 빠짐없이 출력해 줘. 2. 기존의 Tailwind CSS 클래스, Wanted Sans 웹폰트, `word-break: keep-all;` 속성은 절대 삭제하거나 변경하지 마. 3. 아래의 [수정 항목]만 찾아서 바꿔줘: - 프로젝트 제목: [내 프로젝트 이름, 예: 나만의 업무 도우미] - 슬로건: [내 웹 한 줄 소개] - 제작자 정보: [내 이름 / 이니셜] - 개요 본문: [이 도구가 왜 필요한지 2~3문장] [HTML 원본 코드] (여기에 starter-kit/index.html 코드 붙여넣기)
3

AI가 뱉은 코드를 내 파일에 넣고 브라우저로 열기

AI가 출력한 코드 블록 오른쪽 위의 Copy Code를 누른 뒤, 메모장이나 VS Code에서 내 index.html 파일을 열고 전체 선택(Ctrl+A) 후 붙여넣기(Ctrl+V)하고 저장(Ctrl+S)합니다. 크롬 브라우저를 새로고침(F5)하면 내 이름이 적힌 화면이 짠! 나타납니다.

4

전 세계 인터넷에 무료 배포 & 스마트폰 확인!

무료 호스팅 서비스(Netlify Drop: app.netlify.com/drop)에 내 폴더를 마우스로 휙 끌어다 놓기만 하면, 5초 만에 나만의 실제 인터넷 주소(https://내이름.netlify.app)가 탄생합니다. 내 스마트폰으로 열어보고 가족 단톡방에 링크를 공유하세요!

WEEK 02 · 문맥 통제 ⏱️ 실습 소요 시간: 약 35분

거짓말쟁이 AI를 똑똑한 비서로 길들이기 (내 문서 가두기 & 출처 카드)

AI에게 내 메모나 회사 안내문을 건네주고 "없는 이야기는 절대 지어내지 마!" 하고 안전한 울타리를 칩니다. 요약된 문장마다 [출처: 제N조]를 인용하는 3단 정보 카드를 내 웹페이지에 결합합니다.

💡 원장님의 3분 이야기 · 문맥 울타리 치기

"문서에 없으면 '모릅니다'라고 말하게 만들기"

AI는 모르는 질문을 받으면 부끄러워서 그럴듯한 거짓말(환각)을 지어냅니다.

해결책은 간단합니다! "내가 준 이 종이 안에서만 찾아보고, 여기에 안 적혀 있으면 '제공된 문서에 없습니다'라고 정직하게 말해!"라고 규칙을 거는 것입니다. 이것이 기업들이 수억 원을 들여 구축하는 RAG(검색 증강 생성)의 가장 기초적이고 완벽한 시작입니다.

📌 프롬프트 2-1: 원문 가두기 & 3단 요약 카드 추출

너는 팩트 기반 정보 검증 전문 에디터야. 내가 아래 제공하는 [참고 원문 문서]만을 근거로 삼아 정보를 요약해 줘. [엄격한 신뢰성 규칙] 1. 문서에 명시되지 않은 사실은 절대 추측하거나 상상해서 지어내지 마라. 2. 문서에서 찾을 수 없는 질문이 있다면 "제공된 문서에 해당 내용이 없습니다"라고 솔직하게 답변해. 3. 모든 요약 문장 끝에는 반드시 원문의 출처(단락 제목이나 조항)를 [출처: ...] 형태로 명기해. [요약 형식: 3단 카드 규격] 다음 3가지 카드로 딱 떨어지게 정리해 줘: - CARD 01 [핵심 배경과 목적]: 2문장 요약 + [출처] - CARD 02 [해결책 및 주요 데이터]: 2문장 요약 + [출처] - CARD 03 [주의사항 및 실행 팁]: 2문장 요약 + [출처] [참고 원문 문서] (여기에 내 안내문, 메모, 기획서 텍스트 500자 붙여넣기)

💡 원장님의 3분 이야기 · 스킬의 정체

"스킬(Skill)은 마법이 아니라 '업무 매뉴얼'입니다"

사람들이 'AI 에이전트 스킬'이라고 하면 엄청난 컴퓨터 소스코드를 생각합니다. 하지만 실제로는 "우리 회사는 이 글꼴만 쓰고, 이 2가지 색만 써!"라고 꼼꼼하게 적어둔 마크다운 지침서 문서에 불과합니다.

ChatGPT의 맞춤 설정(Custom Instructions)에 이 지침서를 1번만 복사해 두면, 앞으로 어떤 화면을 만들어달라고 해도 자동으로 전문가 디자이너처럼 정갈하게 뽑아줍니다.

📌 프롬프트 3-1: 챗봇 맞춤설정에 넣을 안티-슬롭 DESIGN.md

# [송도 AI 아카데미 안티-슬롭 2색 디자인 원칙] 너는 엔지니어링 냄새가 나지 않는 정갈한 디지털 프로덕트 디자이너다. 나에게 웹 UI 코드를 작성해 줄 때는 아래의 원칙을 반드시 준수한다. 1. 컬러 제한: - 촌스러운 보라색(#7c3aed), 핑크, 형광 네온 컬러를 절대 메인으로 사용하지 않는다. - 단 2가지 색상만 사용한다: 메인 잉크색(Slate-900 / #0f172a), 포인트 강조색(Teal-700 / #0f766e). - 배경은 눈이 편안한 오프화이트(#f8fafc)와 순백색 카드(#ffffff)를 중첩한다. 2. 타이포그래피 (한글 최적화): - 모든 텍스트 컨테이너에 `word-break: keep-all;`을 필수로 적용하여 단어가 어색하게 쪼개지지 않도록 한다. - 제목 태그(h1, h2, h3)에는 `text-wrap: balance;`를 적용하여 양쪽 균형을 맞춘다. 3. 레이아웃: - 불필요하고 요란한 3D 회전 애니메이션은 배제하고, 마우스 호버 시 부드러운 1~2px 상승 효과만 절제되게 허용한다.

어려운 자바스크립트 함수 문법을 몰라도 괜찮습니다! AI에게 "기본 요금은 10만 원이고, 인원수 버튼을 누를 때마다 2만 원씩 곱해서 실시간 총액에 찍어줘!"라고 일상의 언어로 규칙을 주면, AI가 알아서 안전한 계산 스크립트를 조립해 줍니다.

📌 프롬프트 4-1: 기존 화면 안 깨먹고 계산기만 쏙 붙이기

너는 인터랙티브 프론트엔드 엔지니어다. 내 기존 웹페이지의 1~3주차 헤더, 프로필, 3단 요약 카드는 절대 삭제하거나 위치를 바꾸지 말고, `WEEK 04 SLOT` 자리에 [실시간 비용/견적 계산기] 섹션을 추가해 줘. [계산기 요구사항] 1. 입력 항목: - 기본 옵션 선택 (라디오 버튼 또는 클릭 카드 형태) - 수량 증가/감소 (+, - 버튼) - 추가 할인 체크박스 2. 동작 원칙: - 버튼을 누를 때마다 브라우저 새로고침 없이 즉각 하단 [예상 합계 금액] 숫자가 콤마(,)와 함께 재계산되어야 한다. - 0 이하의 음수 입력은 방어해야 한다. 3. 코드는 생략 없이 완성형 전체 HTML로 출력해 줘.

💡 원장님의 3분 이야기 · 실패 두려움 없애기

하지만 "언제든 버튼 한 번으로 과거로 돌아갈 수 있는 백업 타임머신"이 내 손에 쥐어져 있다면 어떨까요? 아무리 컴퓨터를 고장 내도 1초 만에 살려낼 수 있으니, 두려움 없이 마음껏 실험하고 고칠 수 있습니다!

📌 프롬프트 5-1: 4단 에러 리포트 & 안전 수정 지시

내 웹페이지에서 문제가 발생했어. 아래 4가지 상황을 보고 원인을 찾아 안전하게 수정해 줘. 1. [현재 겪고 있는 증상]: - [예: 계산기에서 플러스(+) 버튼을 눌러도 숫자가 올라가지 않고 그대로 멈춰 있음] 2. [원래 기대했던 동작]: - [예: 버튼을 누르면 숫자가 1씩 올라가고 총금액에 반영되어야 함] 3. [의심되는 에러 문구 (F12 콘솔에 보이는 글자)]: - [예: Uncaught TypeError: Cannot read properties of null] 4. [수정 원칙]: - 다른 정상 작동 영역(헤더, 요약 카드 등)은 절대 건드리지 마. - 문제 원인이 무엇이었는지 초등학생도 이해할 수 있게 2줄로 설명하고, 수정된 전체 코드를 출력해 줘.

🎓 원장님의 수료사 · 진정한 자립
