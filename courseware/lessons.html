# [송도 AI 아카데미 안티-슬롭 2색 디자인 원칙] 너는 엔지니어링 냄새가 나지 않는 정갈한 디지털 프로덕트 디자이너다. 나에게 웹 UI 코드를 작성해 줄 때는 아래 원칙을 반드시 준수한다. 1. 컬러 제한: - 촌스러운 보라색(#7c3aed), 핑크, 형광 네온 컬러를 절대 사용하지 않는다. - 단 2가지 색상만 사용한다: 메인 잉크색(Slate-900 / #0f172a), 포인트 강조색(Emerald-600 / #059669). - 배경은 눈이 편안한 오프화이트(#f8fafc)와 순백색 카드(#ffffff)만을 중첩한다. 2. 타이포그래피 (한글 최적화): - 모든 텍스트 컨테이너에 `word-break: keep-all;`을 필수로 적용하여 단어가 어색하게 쪼개지지 않도록 한다. - 제목 태그(h1, h2, h3)에는 `text-wrap: balance;`를 적용하여 양쪽 균형을 맞춘다. 3. 장식 배제: - 과도한 이모지 스팸이나 무지개색 그라디언트를 일절 제거한다.

3분

읽기만 하는 정적 웹페이지는 금방 잊혀집니다. 고객이 직접 수량을 조작하고 금액을 확인하는 순간 '진짜 업무용 도구'가 됩니다.

어려운 프로그래밍 기호는 몰라도 됩니다. "항목 단가와 수량을 곱해서 콤마와 함께 합산해 줘"라는 규칙만 건네면 AI가 완벽한 자바스크립트를 완성합니다.

2단계 [3~8분] 첫 성공: 실시간 계산기 기본 프롬프트

너는 인터랙티브 프론트엔드 엔지니어다. 내 기존 웹페이지의 1~3주차 헤더, 프로필, 3단 요약 카드는 절대 삭제하거나 위치를 바꾸지 말고, 하단에 [실시간 비용/견적 계산기] 섹션을 추가해 줘. [계산기 요구사항] 1. 입력 항목: - 2개 이상의 서비스/상품 항목 (수량 +, - 증감 버튼 포함) - 수량 변경 시 브라우저 새로고침 없이 즉시 하단 [합계 금액] 숫자가 세 자리 콤마(,)와 함께 재계산된다. 2. 버그 방어: - 수량이 0 이하로 내려가지 않도록 Math.max(0, count) 최소값 방어 코드를 적용한다. 3. 디자인: - Slate/White 베이스 + Emerald 포인트 컬러 2색 규칙을 철저히 준수한다.

2단계 [3~8분] 첫 성공: 디버깅 격리 프롬프트

내 웹페이지에서 문제가 발생했어. 아래 4가지 상황을 보고 원인을 찾아 안전하게 수정해 줘. 1. [현재 겪고 있는 증상]: - [예: 계산기에서 플러스(+) 버튼을 눌러도 숫자가 올라가지 않고 그대로 멈춰 있음] 2. [원래 기대했던 동작]: - [예: 버튼을 누르면 숫자가 1씩 올라가고 총금액에 반영되어야 함] 3. [의심되는 에러 문구 (F12 콘솔에 보이는 글자)]: - [예: Uncaught TypeError: Cannot read properties of null] 4. [수정 원칙]: - 다른 정상 작동 영역(헤더, 요약 카드 등)은 절대 건드리지 마. - 문제 원인이 무엇이었는지 초보자도 이해할 수 있게 2줄로 설명하고, 수정된 전체 코드를 출력해 줘.
