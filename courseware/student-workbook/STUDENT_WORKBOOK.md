## WEEK 02. 내 문서 가두기와 출처 인용 정보 카드 섹션
> **목표**: 내 업무 문서를 요약하고 원문 출처를 대조한 3단 카드를 1주차 웹에 결합하기

### 📋 2주차 실습 체크리스트
- [ ] **1. 원문 문서 준비**: 내가 요약하고 싶은 업무 문서, 기획서, 메모 500자 이상을 준비했는가?

## WEEK 03. 스킬의 실체와 안티-슬롭 2색 디자인 리뉴얼

### 📋 3주차 실습 체크리스트
- [ ] **1. 지침서 등록**: ChatGPT 맞춤설정 또는 Claude 프로젝트 지침에 `DESIGN.md`를 등록했는가?

- [ ] **3. 한글 어절 줄바꿈 검사**: `word-break: keep-all;`이 적용되어 스마트폰에서 단어가 잘리지 않는가?
- [ ] **4. 시선 동선 정돈**: 제목, 본문, 각주의 글자 크기(Font Size) 계층이 3단계로 명확히 나뉘었는가?

## WEEK 04. 화면에 손맛 더하기 (실시간 견적/비용 계산기 장착)
> **목표**: 방문자가 옵션을 누르면 즉시 연산되는 실시간 계산 유틸리티 결합하기

### 📋 4주차 실습 체크리스트
- [ ] **1. 계산기 기획**: 내 프로젝트에 필요한 입력 항목(인원수, 패키지 옵션, 할인 등)을 정의했는가?
- [ ] **2. 기능 분할 프롬프트**: 프롬프트 4-1을 통해 1~3주차 코드를 훼손하지 않고 계산기를 결합했는가?
- [ ] **3. 실시간 반응 확인**: 버튼이나 체크박스를 누를 때 새로고침 없이 즉시 총금액이 변경되는가?
- [ ] **4. 사이드 이펙트 점검**: 계산기를 붙인 뒤 상단 헤더나 2주차 요약 카드 디자인이 틀어지지 않았는가?
- [ ] **5. 재배포 후 직접 터치 테스트**: 스마트폰 화면에서 버튼 터치가 부드럽게 작동하는가?

## WEEK 05. 에러가 나도 당황하지 않는 심화 디버깅 & 복구(Rollback)
> **목표**: 코드를 직접 고치지 않고 4단 프롬프트로 버그를 잡고, 백업본으로 안전 복구하기

### 📋 5주차 실습 체크리스트
- [ ] **1. 강사의 고의 버그 주입**: 강사가 제공한 오류 코드(버튼 먹통 버그)를 내 파일에 적용해 보았는가?
- [ ] **2. F12 콘솔 에러 확인**: 크롬 개발자 도구(F12) 콘솔 창을 열어 빨간색 에러 메시지를 확인했는가?
- [ ] **3. 에러 4단 프롬프트 전달**: 증상·에러 문구·기대값·수정 위치 4가지를 AI에게 정확히 전달했는가?
- [ ] **4. 안전 롤백 체험**: 코드가 수습 불가능할 때 `index_backup.html`로 10초 만에 되돌리는 복구를 체험했는가?
- [ ] **5. 내 오답 노트 1호 완성**: 오늘 배운 에러 유형과 대처 프롬프트를 기록해 두었는가?

## WEEK 06. 기능 검증 4대 시험지(Eval) 통과 & 수료 실전 테스트
> **목표**: 강사 도움 없이 새로운 요구사항 1개를 스스로 수정·배포하고 실제 사용자 검증 통과하기

### 📋 6주차 수료 실전 체크리스트 (합격 기준: 4개 모두 PASS)
- [ ] **[Eval 1. 정상값 검증]**: 모든 옵션 선택과 계산 로직이 정상 데이터에서 오류 없이 동작하는가?
- [ ] **[Eval 2. 빈칸/예외 검증]**: 수량에 0이나 음수를 넣어도 계산기가 터지지 않고 정상 방어하는가?
- [ ] **[Eval 3. 사이드 이펙트 검증]**: 기능 조작 후에도 전체 페이지 레이아웃이 단 1px도 깨지지 않는가?
- [ ] **[Eval 4. 모바일 반응형 검증]**: 스마트폰 가로 폭(375px)에서 가로 스크롤 없이 완벽히 정렬되는가?
