## ⚠️ [필수 제1원칙] 안전 백업(롤백) 습관
> **"AI에게 수정을 시키기 전에, 무조건 정상 작동하던 파일을 복사해 둔다."**

AI는 가끔 기존 코드를 멋대로 지우거나 누락합니다. 이때 당황하지 않는 가장 강력한 무기는 **백업 복사본**입니다.
1. 작업 폴더에서 `index.html` 파일을 클릭합니다.
2. `Ctrl + C` 누른 뒤 `Ctrl + V`를 눌러 복사본을 만듭니다.
3. 복사된 파일 이름을 **`index_backup.html`**로 바꿔둡니다.
*(※ 코드가 꼬이거나 화면이 망가지면 이 백업 파일로 언제든 되돌릴 수 있습니다.)*

## 📋 4단계 실전 실습 가이드

### STEP 1. 스타터 코드 열고 AI 대화창 준비하기
1. 메모장이나 VS Code에서 제공된 **`index.html`** 파일을 엽니다.
2. 전체 선택(`Ctrl + A`) 후 복사(`Ctrl + C`)합니다.
3. ChatGPT 또는 Claude 대화창을 새로 엽니다.

---

### STEP 2. AI에게 '1단계 커스터마이징' 프롬프트 전달하기
아래의 퓨샷(Few-Shot) 템플릿을 그대로 복사하여, 대괄호 `[ ]` 안의 내용만 내 정보로 채운 뒤 AI에게 보냅니다.

```markdown
너는 시니어 프론트엔드 퍼블리셔이자 친절한 코딩 튜터야.
내가 아래에 제공하는 [기존 HTML 코드]를 바탕으로, 내 정보와 프로젝트에 맞게 내용을 수정해 줘.

[지침 사항]
1. 기존의 Tailwind CSS 디자인, 한글 폰트(Wanted Sans), 어절 줄바꿈(keep-all) 구조는 절대 건드리지 마.
2. 코드를 중간에 `<!-- 생략 -->` 처리하지 말고, 전체 완성된 HTML 코드를 한 번에 출력해 줘.
3. 아래의 [내 변경 사항]을 코드 안의 수정 포인트에 정확히 반영해 줘:
   - 프로젝트 제목: [예: 2026 송도 글로벌 AI 포럼 안내서]
   - 슬로건: [예: 실리콘밸리와 송도를 잇는 차세대 AI 실전 워크숍]
   - 내 이름 및 이니셜: [예: 이민준 (Minjun Lee) / 🚀]
   - 내 한 줄 소개: [예: 마케터에서 AI 바이브 빌더로 첫 웹 도구를 만들고 있습니다.]
   - 개요 설명: [예: 이 행사는 AI를 실무에 바로 적용하고 싶은 분들을 위해 기획되었습니다.]
   - 푸터 서명 이름: [예: 이민준]

[기존 HTML 코드 전문]
(여기에 복사한 index.html 코드를 붙여넣으세요)
```

---

### STEP 3. 내 컴퓨터에서 바로 확인하기 (로컬 검증)
1. AI가 완성해 준 코드를 복사(`Copy code`)합니다.
2. 메모장으로 돌아와 기존 내용을 모두 지우고 붙여넣은 뒤, **`Ctrl + S` (저장)**를 누릅니다.
3. 저장된 `index.html` 파일을 더블클릭하여 크롬 브라우저에서 엽니다.
4. 내 이름과 프로젝트 제목이 예쁘게 반영되었는지 확인합니다!

---

### STEP 4. 전 세계 무료 배포 (30초 만에 링크 생성)
서버를 설치하거나 결제할 필요가 없습니다. 글로벌 무료 웹 호스팅 서비스인 **Netlify Drop**을 이용합니다.

1. 크롬 브라우저에서 **[https://app.netlify.com/drop](https://app.netlify.com/drop)** 에 접속합니다.
   *(무료 계정으로 로그인되어 있으면 바로 업로드 화면이 나옵니다)*
2. 화면 중앙의 점선 상자(`Drag and drop your site output folder here`)를 확인합니다.
3. 내 `index.html` 파일이 들어있는 **폴더 자체를 마우스로 끌어서 점선 상자에 털어 넣습니다(Drag & Drop)**.
4. 10~20초 뒤 화면에 초록색 불이 켜지며 **`https://xxxx-xxxx.netlify.app`** 형태의 무료 인터넷 주소가 생성됩니다!
5. 링크를 클릭해 열어보고, 스마트폰 카카오톡으로 주소를 보내 모바일 화면에서도 깨짐 없이 잘 나오는지 확인합니다.

## 🛠️ Day-1 트러블슈팅 FAQ

### Q1. AI가 코드가 너무 길다고 중간을 `/* 이전 코드 동일 */`로 생략했어요!
- **원인**: AI가 불필요하게 타이핑을 아끼려는 현상(토큰 절약)입니다.
- **해결 프롬프트**:  
  > *"코드를 절대 생략하지 말고 `<!DOCTYPE html>`부터 `</html>` 끝까지 단 한 줄도 빠짐없이 전체 코드를 완성형으로 다시 써줘."*

### Q2. 한글 글자가 네모나 깨진 글자(???)로 나와요!
- **원인**: 메모장에서 저장할 때 인코딩이 ANSI나 CP949로 설정된 경우입니다.
- **해결책**: 메모장에서 `다른 이름으로 저장(Save As)`을 누른 뒤, 하단의 **인코딩(Encoding)** 옵션을 반드시 **`UTF-8`**로 선택하고 저장하세요.

### Q3. Netlify에 폴더를 올렸는데 'Page Not Found (404)'가 떠요!
- **원인**: 메인 파일 이름이 `index.html`이 아니거나(예: `starter.html`, `main.html`), 하위 폴더 안에 또 폴더가 들어가 있는 경우입니다.
- **해결책**: 파일 이름을 소문자 **`index.html`**로 정확히 맞추고, 그 파일이 바로 들어있는 폴더를 드래그하세요.
