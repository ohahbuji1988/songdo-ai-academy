# 😈 Devil's Advocate (악마의 변호인)

> **"당신의 모든 생각은 반박될 수 있습니다."**  
> 세상의 안일한 합리화, 나태함, 논리적 비약을 조목조목 해체하는 안티-슬롭(Anti-Slop) AI 시비 봇.

---

## 💡 이 프로젝트로 배울 수 있는 것 (AI의 본질)

1. **에이전트의 실체는 '역할(Role)과 제약(Constraint)'입니다.**
   - 거창한 인공신경망 코딩 없이도, **"너는 악마의 변호인이며, 무조건 논리 결함을 진단하고 타격 강도를 매겨라"**라는 명확한 디렉팅만으로 사람의 마음을 흔드는 에이전트가 완성됩니다.
2. **듀얼 엔진 구조 (Offline Preset + Live LLM Adapter)**
   - API 키가 없는 친구들에게 링크만 줘도 30여 개의 재치 있는 뼈 때림 알고리즘으로 즉시 즐길 수 있습니다.
   - 본인의 Gemini API 키를 넣으면 실시간 생성형 AI로 전환되어 세상 모든 문장에 무제한으로 시비를 겁니다.

---

## 🎨 적용된 디자인 원칙 (`frontend-design` & `taste-skill`)

- **Anti-Slop 방침**: 보라색 네온 그라데이션, 둥글둥글한 싸구려 카드, 의미 없는 아이콘 도배 금지.
- **Obsidian & Lucifer Crimson**: 차가운 옵시디언 블랙(`--bg: #090a0f`)에 도발적인 루시퍼 크림슨(`--accent: #ff334b`)으로 날카로운 심문실 분위기 연출.
- **Micro-Interactions**: 타격 강도(Damage Meter) 프로그레스 바 애니메이션, 1초 복사 공유 카드, 반응형 모바일 최적화.

---

## 🚀 실행 및 배포 방법

### 1. 로컬에서 바로 열기
* `index.html` 파일을 더블 클릭하면 기본 브라우저에서 즉시 실행됩니다.

### 2. 친구들에게 웹 링크로 배포하기 (무료 1분 컷)
* **Vercel / Netlify Drop**: [netlify.com/drop](https://app.netlify.com/drop)에 접속하여 이 `devils-advocate` 폴더를 통째로 드래그 앤 드롭하면 즉시 전 세계 접속 가능한 `https://xxx.netlify.app` 링크가 발급됩니다.
* **GitHub Pages**: 본인 GitHub 레포지토리에 올리고 Settings -> Pages에서 배포를 활성화하면 끝납니다.
