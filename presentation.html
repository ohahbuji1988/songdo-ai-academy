디지털 자립의 위계

단순 조립자를 넘어, 문제를 해결하는 '실전 디렉터'로

LEVEL 1 단순 관망자

AI 챗봇에 몇 문장 던져보고 신기해하지만, 대화창 밖으로 나만의 결과물을 꺼내지 못하는 단계.

LEVEL 2 블록 조립자

남들이 만든 코딩 템플릿을 복붙해 보지만, 에러가 나면 원인을 찾지 못해 포기하는 단계.

LEVEL 3 실전 디렉터 (우리의 목표)

문법 암기 없이 AI에게 명확한 제약을 지시하고, 당일 배포와 복구를 스스로 완결하는 자립 단계.

정직한 원칙

수강생과 학부모께 드리는 3대 안심 약속

약속 01 숨은 종량제 0원 원칙

강의 결제 후 추가 API 비용이나 서버 유지비가 들지 않는 로컬/무료 호스팅 스택을 전수합니다.

약속 02 Day-1 첫날 즉시 배포

이론만 4주 듣다 지치지 않습니다. 수업 첫날 30분 만에 내 이름이 걸린 실제 웹페이지를 배포합니다.

약속 03 안티슬롭 정제된 디자인

어색한 번역투 문구와 촌스러운 보라색 AI 템플릿을 배제하고, 애플 감성의 미니멀 UI를 체화합니다.

조기 성공 경험

첫날 30분 만에, 전 세계 인터넷에 내 사이트가 열립니다

Day-1 실시간 검증 클라우드 서버 가입 없는 1분 배포

복잡한 터미널 명령어 없이, 마우스 드래그 한 번으로 스마트폰과 PC 어디서나 열리는 진짜 URL 링크를 발급받습니다.

단 하나의 프로덕트를 점진적으로 완성하는 6주 로드맵

1~2주차 상세

프롬프트 제어와 업무 맥락 주입

1주차 AI 멘탈 모델 & 조기 배포

AI의 컨텍스트 윈도우와 토큰 처리 메커니즘을 파악하고, 단 30분 만에 첫 HTML 페이지를 세상에 배포합니다.

2주차 컨텍스트 카드 & 할루시네이션 방어

매장 규정이나 업무 데이터를 담은 '컨텍스트 카드'를 작성하여, AI가 임의로 거짓말하지 못하도록 제약합니다.

3~4주차 상세

안티슬롭 디자인과 실시간 인터랙션 구축

3주차 안티슬롭 반응형 UI 디자인

흔한 AI 템플릿의 보라색 그라데이션을 걷어내고, 여백과 타이포그래피 중심의 가독성 높은 모바일 UI를 구현합니다.

4주차 실시간 인터랙티브 계산 엔진

단순 정적 화면을 넘어, 사용자가 수량을 누르면 즉시 합계와 할인율이 산출되는 실전 계산 로직을 연결합니다.

5~6주차 상세

3초 타임머신 롤백과 실전 런칭

5주차 3초 타임머신 & 격리 디버깅

코드가 꼬였을 때 직전 정상 시점으로 3초 만에 되돌리는 스냅샷 습관과 에러 로그 분리 지시법을 마스터합니다.

6주차 모바일 바로가기 설치 & 실전 배포

스마트폰 홈 화면에 앱 아이콘처럼 설치되는 PWA 웹 링크를 완성하여, 가족과 고객에게 당당히 전달합니다.
