THE REALITY · 문제의 본질

왜 시중의 "프롬프트 100선" 강의는 3일 만에 잊혀질까요?

💬 대화창에 갇힌 복붙

챗봇 대화창에서 메일 초안이나 요약문만 주고받고 끝납니다. 실제로 작동하는 내 도구로 이어지지 않습니다.

💥 오류 발생 시 패닉

AI가 뱉은 코드에 에러가 나면 원인을 짚지 못하고 포기합니다. 안전 복구(Rollback) 습관이 없기 때문입니다.

💸 예측 불가능한 API 과금

복잡한 클라우드 종량제 API 설정에 질려 중도 탈락합니다. 지속 가능한 학습 환경이 무너집니다.

CORE PHILOSOPHY · 현실적인 AI 역량 3단계

우리의 지향점: 자립형 바이브 빌더 (Level 2 Vibe Builder)

LEVEL 1 · 입문 대화형 사용자

챗봇 대화창 안에서 텍스트를 주고받고 메일과 보고서 초안을 작성하는 일반인 단계.

LEVEL 2 · 본 과정의 수료 목표 자립형 바이브 빌더

단 1개의 AI 구독으로 내 아이디어를 웹 화면으로 띄우고, 스스로 오류를 고쳐 재배포하는 실전가.

LEVEL 3 · 전문 연구 영역 코어 시스템 엔지니어

신경망 모델 자체를 훈련하고 대규모 GPU 클라우드 인프라를 직접 설계하는 전문 개발자.

FOUNDATION · 수업을 지탱하는 원칙

수업을 지탱하는 3대 정직한 원칙

01 단일 AI 구독 완결

복잡한 종량제 API 추가 결제가 일절 없습니다. 이미 사용 중인 ChatGPT Plus 또는 Claude Pro 1개와 지정 무료 호스팅 안에서 전 과정을 끝냅니다.

02 점진적 나선형 확장

마지막 주에 허겁지겁 코딩하지 않습니다. 1주 차에 기본 1페이지를 먼저 배포하고, 매주 '요약 카드 ➡️ 디자인 개편 ➡️ 인터랙션 ➡️ 검증'으로 키웁니다.

03 안티-슬롭 디자인 디렉팅

촌스러운 AI 보라색 네온을 배제합니다. 딱 2색 팔레트와 자연스러운 한글 어절 줄바꿈(keep-all)으로 개발자 냄새 없는 정갈한 화면을 마감합니다.

EARLY WIN · 첫날의 성공 체험

첫 수업 30분 만에 내 웹페이지가 인터넷에 뜹니다

30-MINUTE BREAKTHROUGH

"이론만 4주 듣다 지치는 강의는 가라"

첫날 스타터 킷을 받고 AI에게 내 정보를 주입한 뒤, 무료 호스팅을 통해 30분 만에 실제 인터넷 링크(URL)를 띄웁니다. 스마트폰으로 내 화면을 접속하는 순간, 비전공자의 코딩 두려움은 100% 해소됩니다.

SYLLABUS ARCHITECTURE

단 하나의 프로젝트를 매주 확장하는 6주 나선형 로드맵

W1 Day-1 배포 30분 첫 웹 배포 & 백업 습관
W2 문서 가두기 출처 인용 정보 3단 카드 결합
W3 디자인 개편 안티-슬롭 2색 UI & DESIGN.md
W4 인터랙션 실시간 견적/비용 계산기 장착
W5 고의 에러 오류 복구 롤백 & 오답 노트
W6 최종 런칭 4대 Eval 검증 통과 & 자립
PHASE 1 · 멘탈 모델 & 문맥 통제

1~2주차: 거짓말을 차단하는 원문 가두기 기술

WEEK 01 손발 없는 인턴과 Few-Shot 지시

AI가 왜 할루시네이션(거짓말)을 하는지 확률 예측 구조를 이해하고, 모범 예시 3개를 쥐어주는 퓨샷 기법과 안전 롤백 백업 습관을 첫날부터 장착합니다.

WEEK 02 문맥(Context) 주입과 모름 지침 강제

내 사규나 매뉴얼을 입력하고 "없는 내용은 모른다고 답하라"는 가드레일을 칩니다. 답변마다 [출처: 제N조]를 인용하는 3단 카드를 웹에 결합합니다.

PHASE 2 · UI 감도 개편 & 손맛 부여

3~4주차: 안티-슬롭 2색 디자인과 실시간 계산기

WEEK 03 DESIGN.md 지침서와 안티-슬롭 2색 UI

스킬은 대단한 코드가 아니라 '마크다운 업무 매뉴얼'입니다. 촌스러운 보라색 네온을 지우고 딱 2색 팔레트와 한글 어절 줄바꿈(keep-all)을 적용합니다.

WEEK 04 클릭 연산과 실시간 견적 유틸리티

글만 읽던 웹페이지에서 벗어나, 방문자가 옵션을 누르면 새로고침 없이 즉각 금액이 재계산되는 자바스크립트 연산 인터랙션을 장착합니다.

PHASE 3 · 에러 복구(Rollback) & 최종 자립

5~6주차: 버그 해결 훈련과 4대 기능 시험지(Eval)

WEEK 05 고의 에러 복구 실습 & 4단 전달법

강사가 일부러 심어둔 버그를 프롬프트와 백업본으로 복구해 보며, 증상·콘솔오류·기대값을 전달하는 디버깅 대화법과 실패 일기를 완성합니다.

WEEK 06 기능 검증 4대 시험지(Eval) 통과 & 런칭

정상값, 에러 방어, 사이드이펙트 방지, 원문 대조의 4대 시험지를 통과하고 강사 도움 없이 1개 기능을 스스로 고친 뒤 라이브 웹으로 최종 수료합니다.

ENTERPRISE & INSTITUTIONAL SOP

기업 및 공공기관 출강용 운영 표준안 (SOP & 보안)

1. 사내 데이터 보안 가드레일

기업 기밀 및 개인정보(PII)의 외부 프롬프트 주입을 100% 차단하는 안전 프롬프트 작성 수칙 준수.

2. 4대 Eval 정량 수료 리포트

출석률과 함께 '수료생이 실제로 만든 웹 URL 및 4대 기능 검증 통과 데이터'를 사측 담당자에게 정식 제출.

3. 맞춤형 도메인 프로젝트 설계

기업 사내 매뉴얼, 지자체 안내 데스크, 공공 서식 계산기 등 해당 기관 실무에 즉시 쓰이는 도구로 실습.

WHY SONGDO · 왜 송도 AI 아카데미인가?

인터넷 인강에서는 결코 얻을 수 없는 오프라인 밀착 클리닉

기수당 12명 정원 제한

100명씩 모아놓고 일방적으로 떠드는 강의는 끝났습니다. 강사가 수강생의 화면을 직접 보고 에러를 함께 해결하는 밀착 클리닉을 보장합니다.

비용 0원 정직 보증

이미 사용 중인 챗봇 계정 1개 외에는 추가 서버 비용이나 유료 API 과금을 1원도 청구하지 않습니다. 누구나 안심하고 배울 수 있습니다.
