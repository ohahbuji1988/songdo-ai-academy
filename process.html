3. 실전 강의실로 이동 📦 코스웨어 통합 대시보드 🚀 1주차 스타터 웹 화면

1. STARTING POINT · 왜 시작했는가?

"단순 질문과 텍스트 복붙에 지친 사람들에게, 진짜 내 웹 도구를 쥐어주자."

처음에는 게임 아이디어 구상으로 시작했으나, "진짜 사람들에게 필요한 실질적인 AI 교육 프로그램을 기획해보자"는 제안으로 피벗(Pivot)했습니다.

실리콘밸리 빅테크에서 AI 파이프라인을 다루다 귀국해 송도에 정착한 학원장의 페르소나를 세우고, 기존 시중의 '프롬프트 100선', '챗봇과 잡담하기' 같은 겉핥기 강의의 한계를 돌파하기 위한 정직한 6주 실전 코스를 설계하게 되었습니다.

2. DECISION LOG · 핵심 의사결정의 변화

피드백과 검증을 통해 진화한 6대 결정

① 브랜딩 전환: 강남 ➡️ 송도 국제 AI 아카데미 로컬 아이덴티티

단순 입시·단기 학원 밀집지인 강남 이미지를 벗어나, 송도 국제도시의 글로벌 인프라와 빅테크 귀국 원장의 세련된 감도를 결합했습니다.

② 기간 현실화: 4주 초압축 ➡️ 6주 점진적 나선형 완성 학습 난이도 조정

비전공자가 4주 만에 배포와 디버깅을 다 소화하는 건 사기에 가깝다는 현실적 판단 아래, 6주로 호흡을 넓혀 체화할 수 있는 나선형 구조로 변경했습니다.

③ 비용 경계선: 완전 0원 허구 ➡️ 단일 유료 구독 + 추가 API 과금 0원 비용 투명성

고성능 코딩 모델(ChatGPT Plus/Claude Pro) 구독 1개는 필수임을 정직하게 인정하고, 대신 복잡하고 불안한 종량제 API 토큰 추가 비용은 0원으로 통제했습니다.

④ 카파시 피라미드 & 수치 제거 (Codex 74점 ➡️ 84점 도약) ChatGPT 검수 반영

'상위 0.05%'나 '상위 20%' 같은 근거 없는 숫자를 모두 털어내고, "AI와 대화하던 사람에서, 내 웹 도구를 만들고 고치는 사람으로"라는 명료하고 당당한 포지셔닝으로 전환했습니다.

⑤ 배포 시점 혁신: 4주차 배포 지연 ➡️ 1주차 Day-1 조기 배포 (Win) 교육 설계 혁신

마지막 주에 허겁지겁 배포하지 않고, 1주 차 첫 수업 30분 만에 1페이지를 먼저 전 세계에 배포해 성공 체험을 안겨준 뒤 매주 기능을 덧붙이도록 개선했습니다.

⑥ 브라우저 직접 편집기 (In-Place Editor) 장착 UX 도구 개발

매번 AI 대화창에 문구 수정을 요청하는 번거로움을 해결하기 위해, 브라우저 화면에서 글자를 직접 클릭해 타이핑하고 [파일로 저장]하면 실제 HTML 파일이 갱신되는 툴바를 개발했습니다.
